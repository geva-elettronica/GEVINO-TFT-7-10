# GEVINO TFT — Demo

▶ **Watch the demo on YouTube: https://youtu.be/IzdNAdZBxVE**

[![GEVINO TFT demo video](https://img.youtube.com/vi/IzdNAdZBxVE/hqdefault.jpg)](https://youtu.be/IzdNAdZBxVE)

This folder contains [`Demo.ino`](Demo.ino), the graphical HMI demo for the **GEVINO TFT** (7"/10")
shown in the video: capacitive multi-touch, an image/keypad interface loaded from the on-board
flash, and fast full-screen image rendering via DMA (Raio RA8876, 1024×600 in ~80 ms).
